# Semantic HTML5 Accessible Portfolio

A multi-page personal portfolio built for the HTML5 Semantic Structure & Accessibility task.

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `contact.html` — Accessible contact form

## Accessibility features
- Semantic HTML5 landmarks
- Skip-to-content link
- Keyboard-friendly navigation
- Visible focus indicators
- Proper form labels and autocomplete
- ARIA status messaging
- Logical heading hierarchy
- Reduced-motion preference support
- Good color contrast

## SEO features
- Unique page titles
- Meta descriptions
- Viewport metadata
- Robots metadata
- Canonical URLs
- `robots.txt`
- XML sitemap
- Descriptive link text

## Run
Open `index.html` in a browser or deploy the folder to Netlify/Vercel/GitHub Pages.

## Lighthouse
Run Lighthouse in Chrome DevTools after deployment. Replace the example canonical/domain URLs with the real deployed URL before the final audit.
